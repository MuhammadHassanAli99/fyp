# AURELIA FYP Proposal — Overleaf

Source of truth for the proposal is **LaTeX**, compiled on [Overleaf](https://www.overleaf.com/) (not generated by Python/Word code).

## Open on Overleaf

1. Go to [https://www.overleaf.com/](https://www.overleaf.com/) and sign in.
2. **New Project → Upload Project**.
3. Upload `fyp-proposal-overleaf.zip` from `docs/overleaf/` (or zip this folder yourself).
4. Open `main.tex` and click **Recompile**.
5. Download **PDF** from Overleaf (Menu → Download → PDF).

If your university asks for Word: after the PDF looks correct, use Overleaf export options available on your plan, or open the PDF and save/export to DOCX from Word/Pages. Do **not** regenerate the proposal with scripts.

## What is filled vs blank

- **Filled** from the AURELIA codebase (Gold marketplace, stack, modules, objectives, methodology).
- **Blank on purpose:** team names, supervisor, literature, SDGs, dates, metric thresholds, signatures.
