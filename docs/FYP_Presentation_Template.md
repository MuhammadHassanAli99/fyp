## Content expectations (for filling the deck)

1. **Title** — project name + all group members with registration numbers  
2. **Problem Statement / Type of Work** — problem being solved; nature of the FYP (e.g. system, app, research)  
3. **Literature Review / Background** — prior work / domain context  
4. **Business Scope** — who benefits; market/business boundaries  
5. **Methodology / Framework** — process or architecture diagram showing study/system logic flow  
6. **Tools and Languages** — stack (languages, frameworks, services)  
7. **Constraints and Limitation** — what is out of scope or constrained  
8. **Work breakdown with timelines** — WBS / Gantt-style plan  
9. **Conclusion** — summary of expected outcomes / contribution  
10. **References** — cited sources  
11. Spare / extra as needed  
12. **Q/A**
